# Code of Conduct

Wir wünschen uns eine freundliche, sachliche und respektvolle Zusammenarbeit – unabhängig von Erfahrung, Herkunft oder Rolle. Technische Kritik ist willkommen; persönliche Angriffe, Belästigung, Doxxing und die Verbreitung privater Daten sind es nicht.

Keine illegalen Inhalte, versteckten Fernzugriffsfunktionen, heimlichen Installer oder Umgehungen von Modellzugriffen beitragen.

Bei sensiblen Sicherheits- oder Moderationsfragen bitte nicht unbedacht öffentliche Issues mit privaten Informationen eröffnen.
